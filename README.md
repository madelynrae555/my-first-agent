# my-first-agent

This project is a starting point for exploring lightweight AI agents. It provides a minimal workspace where ideas can be tested quickly without heavy setup or complex dependencies.

The repository is organized to keep things simple. Configuration lives at the top level, source files can be added as the project grows, and documentation evolves alongside the code.

The current focus is on learning the basics of agent workflows. This includes creating files, editing content, running commands, and verifying results through direct inspection.

Future iterations may add example scripts, automated tests, and integration with external tools. Each addition will build on the same simple foundation established here.

Contributions and experimentation are welcome. The goal is to keep the project approachable while leaving room for more advanced features over time.
